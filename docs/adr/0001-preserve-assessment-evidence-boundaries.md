# Preserve system findings separately from Representative advice

The current engine emits generic pathways, heuristic ranks and unsourced templates; portal consumers must instead use the [assessment contract](../decisions/assessment-contract.md), preserving system findings and evidence separately from attributed Representative edits. We accept explicit unknowns and a new adapter boundary rather than relabelling legacy results or letting manual edits overwrite their provenance: a Signed plan can carry a Representative's sourced judgment without pretending the engine established it. This boundary becomes costly to reverse once Signed plans and audit records depend on it, is surprising beside the existing direct/supported labels, and trades legacy presentation reuse for explainable, attributable records; it authorizes no storage migration, provider commitment or engine rebuild.
