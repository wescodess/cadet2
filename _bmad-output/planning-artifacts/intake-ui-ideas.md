# Intake UI Ideas Exploration

We've generated 3 new premium UI/UX design ideas for the `app/pages/workspace/intake.vue` Guided Intake page using the Stitch MCP. All 3 ideas adhere to the `cadet2` design tokens (Light mode, Inter font, 8px rounded corners, `#2b8cee` blue accent) and are focused on a high-trust, calm aesthetic.

Each idea has both Desktop and Mobile configurations available in the **cadet2 UX App Foundation** Stitch project (`6257021077077987630`).

---

## Idea 1: Split-Panel Flow
This approach uses a structured side-by-side layout on larger screens. A persistent vertical progress bar is kept on the left, giving users a constant sense of orientation, while the right holds an airy "Personal profile" form card. On mobile, this adapts to a top horizontal segmented indicator and stacked flow.
**Why it works:** Excellent for complex forms where anchoring the user in the overall journey prevents them from feeling lost.

## Idea 2: Immersive Full-Screen Wizard
This distraction-free interface strips away side navigation entirely to focus deeply on the active task. It utilizes a centered narrow column on desktop with large, sophisticated typography. Both platforms feature a fixed bottom action bar.
**Why it works:** Highly focused and calm, perfect for avoiding cognitive overload during dense profile inputs.

## Idea 3: Card-Stack Form
A modern, spatial design that layers the form sections as a visual stack of cards. The active "Personal profile" card is elevated, while upcoming steps peek out from behind. On desktop, a contextual help panel sits alongside the active card to answer "Why we ask this".
**Why it works:** Beautiful spatial metaphor for progress. Visually premium while still being highly scannable and practical.
